## 🔴 更新本文档时必须遵守的结构约束（强制）

1. **倒序**：新条目**插到版本区顶部**（最新在最前），**禁止**追加到末尾。
2. **标题**：`## vX.Y.Z ｜ YYYY-MM-DD —— 一句话主题`（主题 ≤ 40 字，细节写进正文）。
3. **分类标签**：每条变更必须以 `[新增]` `[优化]` `[修复]` `[破坏性变更]` 之一开头；
   `[说明]` 仅限**出包号 / 兼容性提示**等元信息，且每个条目最多 1 条。
4. **一条一要点**：每条 **≤ 3 行**，只写「问题 → 结论/做法」，**不写**推导过程与验证输出。
5. **禁止冗余**（违反即视为未完成）：
   - 不写构建/检查结果（`vue-tsc` / `lint` / `cargo check` 通过等）；
   - 不写「沙箱无显示器 / 待真机确认」（见下方通用约定）；
   - 不写「未推送 / 未打标签 / 未触发 CI」（只在发布条目里写一次）；
   - 不重复他条已写过的内容 —— 写「详见 vX.Y.Z」即可；
   - 不贴命令输出、日志片段、实测 JSON。
6. **出包号**写在正文首行：`**出包**：文件包名_版本号.后缀`。

## 通用约定（各条目不再重复）

- 🔴 **GUI 交互**：沙箱无显示器，交互/手感**必须由用户真机确认** —— 不得声称已验证交互。
- 🔴 **发布纪律**：默认只本地提交；`git push` / 打标签 / 触发 CI **需用户逐次明确许可**。
- 🔴 **改动时**：前端 / 后端 / 侧车任一处改动都**必须重新出包**才生效。


## v0.1.1 ｜ 2026-10-28 —— 提示音：内置曼波音效，只随系统通知播放

**出包**：dsh-session-notifier-0.1.1.tgz

- [新增] **内置音效**：包内 `assets/mambo.wav` 经 Host 的 `GET /api/session-notifier/sound` 端点回二进制，Client 复用单个 `<audio>` 播放。
- [新增] **音量可调**：`soundVolume`（0–1，默认 0.8）配滑杆 + 试听按钮；`sound: false` 时系统通知与音效一并静音。
- [修复] **系统通知没声音**：`Notification` 自带音在各平台不一致且换不掉，改为通知恒 `silent: true`、音效完全由插件播放。
- [修复] **`always` 模式重复弹窗**：原判据 `!(shownSystem && background)` 只覆盖后台分支，导致前台时系统通知与页内条同时出现；改由 `planDelivery` 按「系统通知是否真的发出」二选一。
- [优化] **音效只跟系统通知**：页内提示条一律不发声（用户要求），单测以「互斥」断言锁死该不变式。

## v0.1.0 ｜ 2026-10-28 —— 首个版本：会话待办节点的系统通知提醒

**出包**：dsh-session-notifier-0.1.0.tgz

- [新增] **六类提醒节点**：任务跑完、等待审批、弹窗提问、需要登录、运行报错、子任务结束；节点可逐个开关。
- [新增] **双通道提醒**：浏览器系统通知 + 页内提示条 + 标签页标题未读计数，声音提示可选。
- [新增] **点击回到会话**：点通知即调 `uiWorkspace.openSession` 选中提醒所属会话，子会话经 `subagentAddress` 换址。
- [优化] **前台策略互斥**：`always` / `smart` / `never` 三选一不叠加，仅通知发不出去时退回页内条兜底。
- [新增] **免打扰与防抖**：支持跨零点免打扰时段；同类提醒按 `dedupeMs` 去重，不同来源分组互不吞没。
- [说明] 兼容 `dsh >= 0.1.7-rc.2` / Node >= 22；配置存 `$USERPROFILE\.dsh\storages\session-notifier\settings.json`。
